# DKODER — The Career Engine 🚀

> Bright, high-energy, interactive 3D digital experience and comprehensive placement readiness platform for engineering students and colleges.

![DKODER Preview](/public/assets/hero-orbit.jpg)

## 🌟 Overview

**DKODER** is an advanced placement LMS and career intelligence platform reimagined with an electric yellow, warm white, and deep ink visual identity. It features real-time 3D orbital telemetry, interactive code playgrounds, comprehensive company-specific DSA preparation, college cohort management, and competitive leaderboards.

---

## ✨ Key Features

- **Interactive 3D Career Orbit Engine**: Built with Three.js featuring real-time lighting, physical ceramic materials, dynamic orbital rings, and spatial company telemetry HUDs.
- **Company Telemetry & Radar**: Live difficulty metrics and interview weightage for top-tier tech companies (Google, Microsoft, Amazon, Uber).
- **Interactive Question Lab & Code Runner**: Multi-language support (TypeScript, Python, C++, Java) with realistic unit test output execution.
- **Career Tracks & Roadmaps**: 4-phase milestone roadmaps for SDE, Data Systems, Service-to-Product, and Core Engineering tracks.
- **Habit & Streak Engine**: 14-day interactive activity heat map with daily challenges and dynamic XP tracking.
- **National XP Leaderboard**: 3D-styled top-3 podium and searchable rankings across universities.
- **Institutional LMS Cohort Showcase**: Real-time batch performance analytics, campus-wide tracking, and placement cell tools.
- **Transparent Pricing & Plans**: Clear tier comparison with interactive monthly/annual billing switches (25% off).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js (`@types/three`)
- **Animation**: Motion for React (`framer-motion`) + Lucide React
- **Styling**: Vanilla CSS Design Tokens, BEM-inspired modular CSS
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Vanjinathan23/Dkoder.git

# Navigate into the project directory
cd Dkoder

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build

```bash
# Type check and build
npm run build

# Preview build locally
npm run preview
```
